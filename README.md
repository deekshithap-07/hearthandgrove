# Hearth & Grove

Premium nuts website (cashews & almonds) built from the Hearth and Grove inspo PDF.

## Pages

- `index.html` — Home (hero, offerings, story)
- `catalogue.html` — Shop grid
- `about.html` — Belief visual + story
- `nutrition.html` — Benefits, compare tool, allergy flip cards

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

Then visit the URL shown in the terminal (usually http://localhost:3000).

## Notes

- Colours match the PDF palette (browns, gold, nude/gray).
- Contact details, prices, and social links are placeholders — swap them for real ones.
- Product photography uses Unsplash placeholders until brand photos are ready.
